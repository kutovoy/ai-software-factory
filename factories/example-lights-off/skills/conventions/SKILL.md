# Repository conventions

- Branches: `factory/<work-item-id>-<slug>`.
- Commits: one logical change per commit, imperative subject, body explains why.
- Tests: every behaviour change needs a test that fails before the change.
- Pull requests: link the work item, state the verification commands you ran.
- Never merge, never approve, never force-push a shared branch.
