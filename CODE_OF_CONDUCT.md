# Code of conduct

Be respectful and constructive. This project is a place to learn and build;
harassment, personal attacks and discriminatory language are not welcome.

## Expected behaviour

- Assume good intent and critique ideas, not people.
- Keep discussions technical and specific.
- Respect maintainers' time: search existing issues and specs before opening new ones.
- Do not publish other people's secrets, private data or vulnerabilities.

## Unacceptable behaviour

Harassment, threats, discrimination, doxxing, and sustained disruption.

## Reporting

Report concerns privately to the maintainer (Nick Kutovyy) through GitHub's
private contact or the repository's security advisory channel. Reports are
handled confidentially.

This code of conduct follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
